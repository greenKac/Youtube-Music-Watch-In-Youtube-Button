## Description
Quick and dirty way to add a "Watch in Youtube" button at the top of the Youtube Music navbar.

## Why though?
Because Youtube Music has the tendency to randomly NOT display some relevant information (i.e views, likes, upload date) on the musics you're listening to.
Opening the video in "normal" Youtube allows you to take note of this ***very*** important data.

## How to use
- Install a userscript extension (only tested in Violentmonkey)
- create a new userscript
- copy the code from `script.js` over to your new userscript
